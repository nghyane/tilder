# Security

Please report a vulnerability privately, not in a public issue: use GitHub's
**Report a vulnerability** (Security → Advisories) on this repository.

Most useful: a way for the rendezvous server, another user, a device that was
removed, or anyone on the network to read a terminal, a file or a workspace,
to run anything on a machine, or to get a machine or device trusted that the
owner did not approve. `docs/v2/THREAT_MODEL.md` says what each defence is and
which test proves it.

We answer within a few days, fix what is real, and credit you if you wish.
